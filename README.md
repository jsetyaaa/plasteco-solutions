# 🌿 Plasteco Solutions - Landing Page

Landing page resmi untuk **Plasteco Solutions**, sebuah perusahaan yang berfokus pada solusi ramah lingkungan untuk mengurangi limbah plastik. Website ini dirancang untuk menampilkan profil perusahaan, layanan utama, dan ajakan untuk bergabung dalam misi keberlanjutan lingkungan.

## 🛠️ Teknologi yang Digunakan

- HTML5
- CSS3 / TailwindCSS
